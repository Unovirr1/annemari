# СЧАСТЛИВАЯ ДОЛИНА ★ Annemarie's Valley

Веб-версия `annemarie_v2.py` — консольной программы, которая брала случайные
предложения из книги Аннемари Шварценбах «Счастливая долина» (*Das Glückliche
Tal*) и переводила их на русский от первого лица девушки. Теперь то же самое
работает в браузере, в оформлении 1994-95: табличная вёрстка, `<marquee>`,
`<blink>`, радужный разделитель и счётчик посещений.

## Запуск

```bash
./run.sh            # стартует в фоне и печатает адрес
```

Открыть в браузере: <http://127.0.0.1:5000> (если 5000 занят — например
запущен `weather_proj` из соседней папки — приложение возьмёт 5001 и напечатает
тот порт, который получился).

Остановить: `./run.sh --stop`

### Вручную, без скрипта

```bash
.venv/bin/python app.py
```

## Установка с нуля

В системном Python нет `pip`, а venv создаётся без него, поэтому:

```bash
python3 -m venv --without-pip .venv
curl -sS https://bootstrap.pypa.io/get-pip.py -o /tmp/get-pip.py
.venv/bin/python /tmp/get-pip.py
.venv/bin/pip install -r requirements.txt
```

## Как это работает

Ровно как в консольной версии:

1. Вы пишете фразу по-русски.
2. Она переводится на немецкий, самое длинное слово становится ключевым.
3. В книге ищутся предложения с этим словом, берутся три случайных.
4. Они переводятся обратно на русский — но перед подстановкой к немецкому тексту
   добавляется `ich bin ein Mädchen`, чтобы переводчик дал текст от женского лица.
5. Приставки «Я девочка / Я девушка / Я девчонка» вырезаются.
6. Мужские формы прошедшего времени после «я» feminируются через `pymorphy3`
   («пошёл» → «пошла»).
7. `Haschisch` и `Opium` зачёркиваются значками `█` — прямо в немецком тексте,
   *до* перевода, как и в консольной версии, чтобы блоки пережили перевод.
   Русские написания («гашиш», «опиум») тоже маскируются на всякий случай.

Источник предложений — PDF рядом с программой, он разбирается один раз
(≈10 с) и кэшируется в `.corpus_cache.json`.

Озвучивание — Web Speech API в браузере (русский голос, если он есть в системе).

## Файлы

| Файл | Что это |
|---|---|
| `app.py` | Flask: `/`, `/api/generate`, `/api/corpus` |
| `annemarie_core.py` | Вся логика: PDF, выбор предложений, род, цензура |
| `templates/index.html` | Страница в стиле 1995 |
| `static/style.css` | Оформление |
| `static/retro.js` | Запрос к API, печатающий текст, озвучка, счётчик |
| `static/space.png` | Тайл звёздного фона (64×64) |
| `make_background.py` | Пересоздаёт фон; PNG пишется вручную, Pillow не нужен |
| `annemarie_v2.py` | Исходная консольная версия (не изменена) |
| `e2e_check.py` | Проверка API + реального UI в headless Chrome |
| `censor_check.py` | Проверка цензуры: блоки █ и отсутствие слов в книге |

## Отличия от консольной версии

* Событийный цикл один на всё приложение (`annemarie_core._loop`). Изначально
  был `asyncio.run()` на каждый запрос, и `googletrans` падал со
  `Event loop is closed`: его httpx-клиент привязывается к первому циклу, а
  Flask даёт каждому запросу новый поток.
* Перевод теперь с тремя попытками — соединение с Google рвётся.
* PDF разбирается один раз и кэшируется, раньше — при каждом запуске.
* Числа в предложениях вырезаются целиком, а не по одной цифре (в оригинале
  `for i in sentence` заменял символы по кругу и портил слова вроде
  `zweitausendfünfhundert`).
* Цензура `Haschisch`/`Opium` делается в немецком источнике до перевода, как
  в оригинале. Google переведя «█████████» вставляет пробелы — они
  склеиваются обратно in `_squash_blocks`. В консольной версии блоки так и
  оставались с пробелами.
* `pyttsx3` заменён на Web Speech API: в этом окружении нет синтезатора речи.

## Проверка

```bash
./run.sh --e2e
PORT=5001 .venv/bin/python e2e_check.py     # общий: API + заполнение панели
PORT=5001 .venv/bin/python censor_check.py  # цензура: блоки █ и никаких слов
```

Первый проверяет, что API возвращает непустой текст без приставки «Я девочка»
и что панель вывода реально заполняется в браузере. Второй гоняет цензуру на
трёх уровнях: юнит (`censor`/`_squash_blocks`), реальное предложение из книги
с наркотиками через перевод, и живой интерфейс. Оба используют маршрут
`/__e2e__`, который существует только при `E2E=1`.
